## What this changes

### The build list prunes nothing

26 of 26 maps withhold NOTHING - every unit except the three bonus
units is available from the start. The survey plan leaned on this as
the one exact way to narrow a map's possible requirements ("a map that
does not offer a Terp cannot require one"). It yields nothing here.

The dump is not broken: the control run on `story1` reports
`available=2/26` - rift lab and tower only - so it discriminates
perfectly. SPAN maps simply hand you everything and let the map be the
difficulty, which is what "development maps" implies in hindsight.

### Almost nothing is a required objective

25 of 26 maps have NO required objective at all.
The only exception:

- `knucracker19` (Chanson), slot 5

THIS IS NOT THE PROBLEM IT FIRST LOOKED. Measured against a Farsite
control (tools/objflag-control.sh): the `required` flag is trustworthy -
story2 reports slots 0,1,4, story6 reports 2 and story20 reports 0,1,2,5,
all exactly matching REQUIRED_OBJECTIVES. And the danger that mattered -
that `IsMissionComplete()` might be VACUOUSLY TRUE where nothing is
required, which would make the randomizer send a completion check the
moment the map loaded - does not happen: Forgotten Fortress reads
`IsMissionComplete=False` at load, exactly like the Farsite missions.

So each SPAN map is won by its own rule and the mod does not need to know
which: it polls the same `World.IsMissionComplete()` it already polls.
`MissionCompletionStats.IsMissionComplete(spec)` is the persisted record,
and it reads True for beaten Farsite missions and False for unplayed SPAN
ones, so it is a working per-map completion signal.

The objectives being OPTIONAL is a benefit. On Farsite the required
objectives are both the win condition and the checks, which is the race
REQUIRED_OBJECTIVES exists to work around. On SPAN the two are separate:
the map is won by its own rule, and its nullify targets and totems are
pure optional collectibles - which is the shape a location wants.

### Starters are a problem

The roster holds 1 cache(s) in total (knucracker18 x1).
A Farsite mission opens the game because it has a cache collectable
with a rift lab and one tower. With one cache across 26 maps, SPAN
cannot supply that opening, so the seed's first checks have to keep
coming from Farsite missions however the mix is drawn.

### Objective types the model has no slot for

4 map(s) enable the Hold/Survive slot, which no Farsite mission uses
and which `locations.py` has no location for: `knucracker4`, `knucrackerbonus0`, `knucrackerbonus1`, `demobonus4`.

2 map(s) carry map-embedded CPACK units - these ship with the map,
cannot be unlocked and cannot be items:

- `knucracker10`: Crazon[6e0eea34] INVERT[fa739834] MiniFat[c7714839]
- `knucracker20`: Bertha[cdf204b4]
